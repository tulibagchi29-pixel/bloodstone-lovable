## Quick Start to Deploy (Manual Cloudflare)

### 1. Prerequisites
```bash
# Install Wrangler CLI
npm install -g @cloudflare/wrangler

# Verify installation
wrangler --version
```

### 2. Authenticate with Cloudflare
```bash
wrangler login
# This opens a browser to authenticate with your Cloudflare account
```

### 3. Build the Project
```bash
npm run build
# Generates .output/server/index.mjs and .output/server/wrangler.json
```

### 4. Deploy to Cloudflare
```bash
# Deploy using the auto-generated config
wrangler deploy
```

### 5. Verify Deployment
```bash
# View logs
wrangler tail

# Test in browser
open https://shamitbagchi.com/
```

## Important: Cloudflare Dashboard Setup Required

Before deploying, you **must** configure routes in Cloudflare Dashboard:

1. Log in to [Cloudflare Dashboard](https://dash.cloudflare.com/)
2. Select your domain: `shamitbagchi.com`
3. Go to **Workers & Pages** → **Overview**
4. Click **Create Application** → **Create Worker** (name it `bloodstone-lovable`)
5. Once created, go to **Routes** tab
6. Add these routes:
   - `shamitbagchi.com/*` → `bloodstone-lovable`
   - `www.shamitbagchi.com/*` → `bloodstone-lovable`
7. Save

## How the Build Process Works

1. `npm run build` → Vite builds client and SSR
2. Nitro builds the Cloudflare Worker using preset `cloudflare_module`
3. **Automatically generates** `.output/server/wrangler.json` from `wrangler.toml`
4. `wrangler deploy` uses the generated config from `.output/server/wrangler.json`

## Troubleshooting

### Common Issues

**"Could not find wrangler.toml"**
```bash
# Make sure you're in the project root
cd /path/to/bloodstone-lovable
wrangler deploy
```

**"Deployment failed: Not authenticated"**
```bash
# Re-authenticate
wrangler logout
wrangler login
```

**"Build error when deploying"**
```bash
# Clean and rebuild
rm -rf .output
npm run build
wrangler deploy
```

**"Domain not working after deployment"**
1. Verify routes are created in Cloudflare Dashboard
2. Check SSL/TLS settings (set to "Flexible" minimum)
3. Wait 5-15 minutes for DNS to propagate
4. Clear browser cache and try again

**"CPU limits are not supported for the Free plan"**
This has been fixed - CPU limits were removed from wrangler.toml.

**"Warning: Wrangler config main is overridden"**
This is expected! Nitro automatically generates the correct config. Just deploy normally.
